## Install

```sh tab="macOS"
brew install DBase-to/tap/dbase
```

```sh tab="npm"
npx @dbase.to/cli
```

```sh tab="Windows"
scoop bucket add dbase https://github.com/DBase-to/scoop-bucket.git
scoop install dbase
```

Verify the installation:

```sh
dbase --version
```

## Authenticate

Log in so the CLI can access your DBase projects:

```sh
dbase login
```

This opens your browser for OAuth. To use a token instead (useful in CI):

```sh
dbase login --token dbp_your_token_here
```

See [`dbase login`](/docs/commands/login) for all options.

## Initialize a project

Create a new DBase project in the current directory:

```sh
dbase init
```

## Start local development

Spin up a local DBase stack (Postgres, Auth, Storage, etc.):

```sh
dbase start
```

Your local API URL and keys are printed once the stack is ready.

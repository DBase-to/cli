The DBase CLI lets you develop locally, manage your DBase projects, and deploy
from the terminal or CI/CD.

## Quick start

```sh
# Install
brew install DBase-to/tap/dbase   # macOS
npx @dbase.to/cli                 # or via npx

# Authenticate
dbase login

# Start a project
dbase init
dbase start
```

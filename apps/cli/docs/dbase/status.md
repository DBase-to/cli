## dbase-status

Shows status of the DBase local development stack.

Requires the local development stack to be started by running `dbase start` or `dbase db start`.

You can export the connection parameters for [initializing supabase-js](https://dbase.to/docs/reference/javascript/initializing) locally by specifying the `-o env` flag. Supported parameters include `JWT_SECRET`, `ANON_KEY`, and `SERVICE_ROLE_KEY`.
